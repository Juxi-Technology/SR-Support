## 2. 与你手上 PTK7452MG 的匹配

- 原设计舵机是 **PTK7465MG**：23.7×12×26.6 mm，13 g，25T，1520 µs 中位。
- 你的 **PTK7452MG**：23.6×26.9×11.7 mm，12.2 g；把尺寸排序后与 7465 基本同壳体（差 0.3 mm 内），花键常见 25T。**打样前必须量实物**：耳片、出线、舵盘螺丝孔距。
- 舵机座用扎带固定，不依赖耳片孔；如果耳片干涉，可剪耳片/加宽座。
- 力矩差异：7452 在 6V 约 3.4 kg·cm，7465 是 4.5；B 线策略需要按 7452 重训（见 [`../../training/b_line/`](../../training/b_line/)）。

## 3. 打印建议（来自上游）

- 材料 PETG（耐冲击、层间韧性好）；PLA 也能用但脆。
- 0.2 mm 层高、4 圈壁、30–40% 填充；受力方向尽量让层线沿长度。
- **底座**：竖直打印；舵机座内部有桥接，建议树状支撑。
- **大臂**：侧躺打印（竖直板贴床），舵机座开口朝上，基本不需要支撑。
- **小臂**：侧躺打印（连杆贴床），叉板和末端垫圆孔需要少量支撑。
- 试装前用 0.5 mm 间隙检查舵机。

## 4. 装配顺序（来自上游）

1. 两个舵机先回中位（PTK 1520 µs），装舵盘时让手臂竖直向上。
2. 肩舵机放进底座塔顶的座里，扎带固定；舵盘朝 +X。
3. 大臂的肩轮毂套在舵盘上，2×M2 螺丝固定；确认大臂能绕 +X 自由转动。
4. 肘舵机放进大臂顶部座里，轴沿 +Y，扎带固定；舵盘朝 +Y。
5. 小臂叉板从外侧套住肘舵机：+Y 轮毂接舵盘（2×M2），−Y 板用 M3 螺丝/打印销做辅助轴。
6. 末端垫套橡胶 O 圈/皮筋；这是与地面的主要摩擦来源。
7. 电子件：ESP32、IMU、6V/5A 电源/接线放进底座舱；IMU 的 +X/+Y/+Z 与机体一致。
8. IMU 平放在 −Y 舱托盘里，印字 +X 朝前、+Z 朝上，用 VHB/双面胶固定。
9. 上电前手转两个关节全程，确认没有干涉；再按固件 README 标定。

## 5. 打印后必须做的事

- **称重**：B 线上游估计 100–125 g，仿真只有 74.4 g；把实际质量填进 `training/b_line/assets/robot_ptk7452.xml` 的 `mass`，否则 sim2real 不可信。
- **量尺寸**：底座/臂长/肩高/脚位置与 XML 对齐；有差异就改 XML 后重训。
- **查干涉**：上游 `checks/interference.py` 已跑过 0 mm³；你换了 7452 后重新装一次，确认舵机壳/舵盘/线缆不干涉。
- **舵机方向**：按固件 `SERVO_SHOULDER_SIGN`/`SERVO_ELBOW_SIGN` 和 `t` 自检确认。
