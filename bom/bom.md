## 2. 接线（示例）

| 器件 | 引脚 | 接到 | 说明 |
|---|---|---|---|
| Juxi IMU | VCC/3V3 | ESP32-S3 3V3 | 3.3V；不要接 5V |
| Juxi IMU | GND | ESP32-S3 GND | 共地 |
| Juxi IMU | SDA | GPIO6（优先直连） | I²C 100kHz；本机经 CH3 不稳 |
| Juxi IMU | SCL | GPIO7（优先直连） | I²C 100kHz；本机经 CH4 不稳 |
| Juxi IMU | VCC | ESP32 3V3 | **不要接舵机口 V+（6V）** |
| Juxi IMU | GND | CH3/CH4 GND 或 ESP32 GND | 共地 |
| 肩舵机 | 信号 | GPIO4（CH1 示例） | 50Hz PWM |
| 肘舵机 | 信号 | GPIO5（CH2 示例） | 50Hz PWM |
| LED（可选） | — | GPIO2 | 状态灯 |
| 舵机 红 | VCC | 6V/5A 电源 +（转接板 V+） | **不要接 ESP32 3V3/USB 5V** |
| 舵机 棕 | GND | 电源 − / ESP32 GND | 共地 |
| 电容 | 1000–2200µF + 100nF | 舵机 6V/GND 就近 | 注意极性 |
| 保险丝 | 5A | 电源 → 转接板 V+ | 串联 |

**转接板注意：**

- 你的板子是**无源直连 + 级联排针**：确认每个口的 V+/GND/信号顺序一致，插反会烧舵机/板。
- 当前 `config.h` 的 GPIO4/5 只是示例；等实际 GPIO4–18↔CH 映射口述后修改。
- 如果转接板有隐藏的稳压/缓冲/上拉，告诉我型号；B 线固件假设纯直连。
- 不要把 6V/7.4V 接到 ESP32 的 5V/3V3；ESP32 用 USB-C 5V 单独供电，共地。

## 3. 电源建议

- **v0 插电**：ESP32 USB-C 5V；两个 PTK7452 用 **6V/5A** 独立电源；共地；舵机端 1000–2200 µF。
- **想接近 B 线训练的 4.5 kg·cm**：可用 7.4V/5A；PTK7452 支持 4.8–7.4V，但发热/电流/寿命要实测，且策略最好按实际电压重训。
- **不要**用电脑 USB 口、MB102 面包板电源带两个舵机；不要用 5V/3A 适配器（B 线电流/力矩不够）。
- 8 个舵机同时动作：按每个堵转 2–3A 估算，至少 6V **10A+**；v0 不用。
- 电池版（后续）：2S LiPo + 6V/5A BEC；加 BMS/欠压保护。

## 4. 软件/固件提醒

- 当前主固件：[`../firmware/sr_support_b_ptk/`](../firmware/sr_support_b_ptk/)（Juxi B 线，MIT/Apache；PTK7452 参数）。
- 上电默认保持，发 `g` 才跑策略；`s` 保持最后目标，`x` 释放 PWM，`r` 重新初始化。
- `include/policy_b.h` 是 **PTK7465 基线策略**，只用于 bring-up；最终用 [`../training/b_line/`](../training/b_line/) 按 PTK7452/实际质量重训。
- 训练默认 128×128、10 维观测；B 线 180° 的 DR 成功率本身不高，先按保守目标验收。
- 代码 MIT/Apache；硬件 CAD CERN-OHL-S；B 线固件不链接 GPL SCServo。见 [`../docs/licensing.md`](../docs/licensing.md)。
