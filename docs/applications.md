# SR-Support 应用场景分析

> 对象：ESP32 + 6 轴 IMU + 2 个 9g 舵机的低成本主动自扶正装置。  
> 当前形态：插电、3D 打印/裸机、BOM 约 ¥80–160、无电池、无外壳认证。  
> 结论先行：**它现在最适合“教育套件 / 展陈互动 / 密室自动复位道具 / 桌面玩具原型”；真正做成消费级产品，最有潜力的是“打不倒的桌面宠物/陪伴玩具”，但需要电池、外壳、交互、可靠性和认证。** 不建议直接套到车载摆件、重型机器人、医疗康复等场景。

---

## 1. 先明确你卖的是什么

同样是“自扶正”，有四种卖法，场景和要求完全不同：

| 卖法 | 客户 | 价值 | 当前原型适配度 |
|---|---|---|---|
| 卖“能力/模块” | 机器人/玩具厂商 | 给别人的产品加自扶正 | ★★（需要放大扭矩/可靠性） |
| 卖“套件/课程” | 学校、机构、家长 | 教 IMU、舵机、状态机、重心 | ★★★★ |
| 卖“玩具/桌宠” | 消费者 | 情绪价值、互动、IP | ★★（需要电池/外壳/认证） |
| 卖“互动装置/道具” | 展馆、品牌、密室 | 吸睛、自动复位、低维护 | ★★★★ |

**自扶正本身只是“功能”，不是“产品”。** 产品价值来自场景：教学、互动、情绪、品牌、可靠性。

## 2. 现在这套原型最适合的场景（低改造）

### 2.1 STEM / 创客教育套件

- **卖给谁**：中小学创客教室、培训机构、职校、大学工科实验室、家庭教育。
- **为什么合适**：
  - 自扶正是一个“看得见”的反馈控制 demo：IMU 检测 → 状态机 → 舵机动作 → 重心越过支点；
  - 涉及重心、力矩、PWM、I2C、滤波、状态机，课程延展性强；
  - 真正的“自扶正”教育套件很少（多数是自平衡车），差异化明显；
  - 插电版本在教室里反而更安全、更好维护。
- **需要补什么**：课程/教师手册、接线图、分步实验、备件包、亚克力/3D 打印外壳、年龄分级（建议 14+ 或成人指导）。
- **商业模式**：套件 + 课程 + 教师培训 + 备件；开源核心代码/文档做社区，卖硬件和课程服务。

### 2.2 高校 / 科研控制算法平台

- **卖给谁**：控制、机器人、RL 实验室；学生课程设计/竞赛。
- **为什么合适**：
  - 低成本、可复制、可 3D 打印；适合做“自扶正控制/RL sim-to-real”的实验平台；
  - 比自平衡车多一个“倒地恢复”的离散状态机，适合研究混合控制、事件触发、鲁棒性；
  - 已有开源项目用 ESP32 做 self-righting RL arm 的 sim-to-real，说明这个方向有研究需求。
- **需要补什么**：可重复的机械件、传感器标定、数据日志、ROS/上位机接口（可选）。
- **商业模式**：小批量套件、实验室采购、论文/课程合作。

### 2.3 展馆 / 零售 / 品牌互动装置

- **卖给谁**：科技馆、博物馆、商场中庭、品牌快闪店、展会。
- **为什么合适**：
  - “推倒它，它自己站起来”是很强的互动钩子；
  - 插电、固定安装、维护可控；
  - 可放大结构、换更大扭矩舵机，做成品牌吉祥物/展品；
  - 比屏幕互动更有实体感，适合拍照传播。
- **需要补什么**：7×12 小时耐用性、静音、防夹手、防尘/防破坏、可维护结构、灯光/音效、品牌外观。
- **商业模式**：定制装置 + 内容/维护合同；单价高、量小。

### 2.4 密室 / 沉浸式剧场 / 自动复位道具

- **卖给谁**：密室逃脱、剧本杀、沉浸式剧场、主题乐园。
- **为什么合适**：
  - 密室/剧场有大量“道具被推倒/移动后需要复位”的痛点，自动复位可以省人工；
  - 自扶正物体可以做成“推倒后自己站起来”的机关/线索；
  - B2B 客户对价格不敏感，对可靠性和复位逻辑敏感；
  - 可接 DMX/GPIO/中控，融入场景。
- **需要补什么**：自动复位逻辑、失败重试、断电恢复、静音、耐用、可维护、与中控协议对接。
- **商业模式**：按机关/项目定制，高毛利、小批量。

### 2.5 短视频 / 直播道具、企业礼品

- **短视频/直播**： “打不倒”挑战、解压循环、互动直播道具；量小，但传播性强。
- **企业礼品/品牌周边**： “Resilience/打不倒”寓意，定制 logo、配色、包装；插电或电池版；企业客户对单价容忍度高。
- **需要补什么**：外观设计、品牌定制、包装、静音、可靠性。
- **注意**：企业礼品如果面向儿童/桌面长期使用，仍要注意电气安全和夹手风险。

## 3. 稍加改造可产品化（中改造）

### 3.1 打不倒的桌面宠物 / 陪伴机器人（最有消费潜力）

- **概念**：一个桌面小机器人/小摆件，被推倒后自己站起来；配合 LED 表情、声音、触摸/IMU 反应，形成“性格”。
- **为什么有市场**：
  - 桌面 AI 机器人已经在卖“推不倒 + 陪伴”：XGO-Rider2（约 ¥2600，双轮足动态平衡）、RIG-Hover（ESP32-S3、双无刷、赛博不倒翁桌宠、接大模型语音）；
  - 你的方案成本低得多，可以用“机械自扶正 + 表情/声音”切低端/教育/礼品市场；
  - “打不倒”是天然的情绪钩子：被推倒会“生气”，站起来继续陪你。
- **需要补什么**：
  - 电池（LiPo + 保护/充电）、低功耗；
  - 外壳（不能露出舵机/夹手）、配重、防摔；
  - 交互（LED/OLED/蜂鸣器/触摸/语音模块，可选）；
  - 角色/IP/内容（表情、音效、性格）；
  - 可靠性（连续跌落/舵机寿命）、认证。
- **价格带**：¥199–399（基础款）到 ¥599+（带屏/语音/IP）。
- **风险**：自扶正只是卖点之一，消费者买的是“可爱/陪伴/内容”，不是机构本身。

### 3.2 互动宠物玩具（猫玩具）

- **概念**：猫把玩具推倒，它自己站起来/弹回，甚至“反击”（羽毛/激光/声音）。
- **市场信号**：已有大量**被动配重**自扶正猫玩具（$4–15）；主动式（舵机/电机）少，差异点是“会自己站起来/有反应”。
- **需要补什么**：耐咬/耐摔、无小零件、电池安全、静音、猫抓板/羽毛可更换、成本控制。
- **风险**：宠物玩具价格敏感、竞争激烈；主动机构增加故障点；需要宠物安全材料。
- **建议**：先做“被动低重心 + 简单 LED/声音”的廉价版，再考虑主动舵机版。

### 3.3 品牌 / IP 潮玩

- **概念**：不倒翁角色（盲盒/潮玩/联名），推倒后自己站起来；可加灯光/声音。
- **为什么合适**：不倒翁本身有文化认知；“打不倒”适合品牌寓意；盲盒/潮玩有溢价。
- **需要补什么**：IP/设计、模具、表面工艺、包装、玩具安全认证、电池（如果发光/发声）。
- **风险**：IP 和渠道是核心，硬件只是载体；没有 IP 的话容易变成廉价摆件。

### 3.4 教育机器人竞赛 / 自扶正模块

- **卖给谁**：机器人竞赛战队（相扑、救援、循迹）、学校社团。
- **为什么合适**：自扶正能显著提高机器人抗翻倒能力；可以作为 Add-on 模块/套件。
- **需要补什么**：标准安装接口、更高扭矩/更快舵机、抗冲击、供电方案、比赛规则适配。
- **风险**：竞赛市场小，但对性能/可靠性要求高；需要和现有底盘适配。

## 4. 需要重新设计 / 不建议的场景

| 场景 | 为什么 | 结论 |
|---|---|---|
| 小型巡检机器人自扶正模块 | 真实需求存在，但 9g 舵机扭矩/防护不够；需要放大、IP 防护、可靠性验证 | 长期 B2B 方向，不是当前原型 |
| 野外传感器/相机节点 | 需要电池、低功耗、防水防尘、宽温；自扶正只是其中一环 | 长期/定制 |
| 车载摆件 | 安全/法规/暴晒/分散驾驶注意力；被动不倒翁已很便宜 | 不建议 |
| 重型/救援机器人 | 扭矩差几个数量级；需要液压/大扭矩关节 | 不建议 |
| 医疗/康复 | 不能做医疗声明；安全/认证门槛高 | 不建议 |
| 自扶正无人船/浮标 | 用的是低重心被动原理，和舵机方案不同 | 可参考，不是同一产品 |

## 5. 市场信号（别人做到哪了）

- **桌面机器人**：XGO-Rider2（约 ¥2600，双轮足动态平衡、AI 语音、开源）和 RIG-Hover（ESP32-S3、双无刷、赛博不倒翁桌宠、接大模型）说明“推不倒 + 桌面陪伴”有需求，但价格高；低成本机械自扶正可以切低端/教育/礼品。
- **教育套件**：自平衡车套件很多（ELEGOO Tumbller 等），但**真正的自扶正套件很少**（VN Robot Ladybug 1.0 是一个），说明教育市场有空位。
- **宠物玩具**：被动自扶正猫玩具已经很多（$4–15），主动式少；差异点明确，但价格/耐用性是门槛。
- **密室/剧场**：自动复位道具是成熟 B2B 需求（自动复位拼图、自动复位机关），自扶正物体可以做成新机关。
- **自扶正无人船**：杭州蔚海方舟 P8 用低重心被动自扶正，说明“自扶正”在户外设备也有价值，但和你的舵机方案不是同一技术路线。
- **专利注意**：CN109693729（上海电机学院，两个舵机 + 两个支撑架）和 US20250295093A1（自扶正猫玩具）等说明这个方向有专利布局；商用前做 FTO。

## 6. 商业化建议（按优先级）

1. **教育套件 + 课程（最快）**
   - 客户明确、认证压力小（14+ 教育设备）、能讲清楚原理；
   - 卖套件 + 教师手册 + 备件 + 培训；开源核心代码建社区。
2. **展馆/零售互动 + 密室自动复位道具（B2B，高毛利）**
   - 插电可接受、单价高、量小；重点是可靠性和定制服务。
3. **企业礼品 / 品牌周边（定制）**
   - 外观/包装/寓意驱动；适合小批量高溢价。
4. **桌面宠物 / 猫玩具（消费级，量大但难）**
   - 需要电池、外壳、交互、IP、认证、可靠性；建议先做众筹/小批量验证。
5. **B2B 自扶正模块（长期）**
   - 放大扭矩、IP 防护、标准接口；先找 1–2 个机器人/玩具厂商做联合验证。

---

## 7. 产品化前必须补的课

- **可靠性**：连续 1000 次跌落/自扶正；舵机齿轮寿命；MG90S/金属齿轮；舵机保护器；限位。
- **安全**：夹手、舵机堵转发热、电池保护、跌落碎片；儿童玩具需 GB 6675/GB 19865、CE/EN71、FCC（如果无线）、UN38.3（电池）。
- **成本**：当前 BOM ¥80–160；消费零售通常要 3–5 倍定价；教育/B2B 可承受更高。
- **专利**：CN109693729、US20250295093A1 等；商用前 FTO。
- **内容**：教育需要课程；桌宠需要性格/IP；展陈需要故事；没有内容，自扶正只是一个机构 demo。

---

## 8. 一句话建议

**先卖“教育套件 + 展陈/密室道具”，验证机构可靠性和付费意愿；再考虑“打不倒的桌面宠物”这种消费级产品。** 不要一上来做通用消费玩具——自扶正只是功能，真正决定产品成败的是场景、内容、可靠性和成本。
