# 04 标定与检查

## 4.1 遥测格式

串口每 250 ms 输出一行遥测，监控工具每 5 秒汇总一条：

```text
up -0.01 +0.02 +1.00 | w  0.0  0.0  0.0 | q +0.00 +0.00 | qd  0.0  0.0 | run
```

| 字段 | 含义 |
|---|---|
| `up` | 世界 up 向量在机体坐标下的分量（x 前、y 左、z 上） |
| `w` | 三轴角速度（rad/s） |
| `q` | 当前关节指令角（肩、肘，rad） |
| `qd` | 关节指令角速度 |
| 末尾 | `run` / `hold` / `manual` / `auto` |

## 4.2 IMU 检查

1. 让机器人静止直立，确认 `up≈(0, 0, 1)`，`w≈0`；
2. 机器人**站立在水平桌面**上保持静止，发送 `c` 同时标定陀螺与加速度计零点
   （提示 `calibrating gyro+accel...`；加速度零点写入 NVS，打印 `accel bias ... (saved)`
   才算成功；若提示 `rejected` 说明没放平或还在动，重新放稳再来）；
3. 缓慢左右、前后倾斜，确认 up 的 x/y 分量方向正确、无跳变；
4. 若 up 的 x 或 y 方向与预期相反，发送 `i` / `j` 翻转 IMU 轴符号后重新 `c`；
5. 躺姿检查：放倒静置 2 秒后 up 应稳定且与实际姿态一致（如侧躺的 −Y 姿态 up≈(0,−1,0)、
   底座面贴平）；若躺姿下 up 长期偏斜 5° 以上，往往就是加速度计零点未标定，重做第 2 步。

## 4.3 舵机检查

| 检查 | 方法 | 预期 |
|---|---|---|
| 中位脉宽 | 发送 `k` | `shoulder 1681 us, elbow 1456 us`（2026-11 视觉中位固化值；以 4.5 节重新标定为准） |
| 肩中位微调 | `o` / `p`（每次 ±10 µs） | 手臂竖直时 `q=0` |
| 方向 | `m 0.5 0` / `m 0 0.8` | 肩 + 使大臂向 −Y；肘 + 使小臂向 +X |
| 符号翻转 | `v`（肩）/ `b`（肘） | 方向反了才用 |
| 自检 | `t` | 两关节小幅动作后回中 |
| 回中 | `m 0 0` 或 `r` | 手臂竖直 |

关节限位（固件）：

- 肩：手动命令 `[-1.85, +1.82]` rad；肘：机械 `±1.55` rad（执行器内部可达）；
- `m` 手动命令的肘部限位为 `[-0.90, +0.70]` rad；
- PWM 输出范围 500–2500 µs，50 Hz。

## 4.4 四种躺姿与跌倒门

| 姿态 | 监视器 up | 物理含义 |
|---|---|---|
| `pitch_pos` | `(-1, 0, 0)` | 机体顶部指向 +X |
| `pitch_neg` | `(+1, 0, 0)` | 机体顶部指向 −X |
| `roll_pos` | `(0, +1, 0)` | 机体顶部指向 −Y |
| `roll_neg` | `(0, -1, 0)` | 机体顶部指向 +Y |

跌倒门条件（固件）：

```text
up_z < 0.30 且 |ω| < 0.9 rad/s，连续 25 拍（0.5 s）
```

满足后才会打印 `getup start pose=...` 并开始扶正。因此把机器人摆成躺姿后需要**松手并
保持静止约 0.5 秒**；放下后立即乱摆通常是手还在扶着或身体仍在滚动。

验证方法：分别把机器人摆成上表四种姿态，松手静止，观察串口是否在 0.5 秒内出现
`getup start pose=<对应姿态>`。

## 4.5 中位/零点校准（方向键工具 + `z`）

固件约定 q=0 = "手臂竖直、大臂小臂成一条线"的视觉中位。换齿、拆装舵盘或换舵机后按此流程定零：

1. 电池 + Type-C 都接上（舵机要有电），运行：

   ```bash
   .venv/Scripts/python.exe tools/hw_shoulder_range.py
   ```

   界面常驻三行、原地刷新：`↑`/`↓` = 大臂 ±0.05 rad，`←`/`→` = 小臂 ±0.05 rad
   （按住 Shift = ±0.20）；`z` = 当前姿态设为中位；`k` = 读中位；`n` = 回中；`q` = 退出。

2. 用方向键摆到**目测竖直、两臂成一条线**，按 `z`，固件打印：

   ```text
   zero set: shoulder XXXX us, elbow XXXX us (current pose is now q = 0)
   ```

3. 把这两个 µs 写回 `config.h`（`SERVO_SHOULDER_CENTER_US` / `SERVO_CENTER_US`），并把
   `EXEC_REF*` 与 `training/b_line/getup_reference_b39.py` 的全部路点按相同差值平移
   （肩/肘各 −Δ rad），重新烧录；
4. 复测四个方向，确认扶正动作和收臂姿态都正常。

> `z` 只改内存，重启恢复旧零点；确认好用后必须执行第 3 步固化，否则扶正序列的物理姿态
> 会漂移。误按 `z` 没有破坏性：重新摆好再按一遍即可覆盖。
