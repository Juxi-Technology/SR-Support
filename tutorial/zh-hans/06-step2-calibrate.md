# 06 第二步：标定

> **成品用户可跳过本页**：出厂已逐台完成标定与验证。仅在更换舵机/IMU、重新装盘、换齿，
> 或升级固件后怀疑标定漂移时，按本页顺序重新做一遍。

按下面的顺序完成四项标定/检查。每项的详细方法在括号中的页面里。

## 6.1 陀螺 + 加速度计标定

机器人**站立在水平桌面**上保持静止，串口发 `c`：

- 打印 `gyro bias ...` 与 `accel bias ... (saved)` 才算成功（加速度零点写入 NVS，重启自动加载）；
- 若打印 `accel cal rejected`：机器人没放平或还在动，重新放稳再来；
- 详细说明与躺姿检查方法见 [03 调试页 3.2](./03-debug-and-checks)。

## 6.2 舵机方向自检

串口发 `t`，确认：

- 肩 `q>0` → 大臂向 **−Y**；肘 `q>0` → 小臂向 **+X**；
- 方向反了用 `v` / `b` 翻转，或重装舵盘（见 [03 调试页 3.3](./03-debug-and-checks)）。

## 6.3 中位零点

出厂已固化（肩 1681 µs / 肘 1456 µs），**正常可跳过**。仅当换齿、拆装过手臂或收臂后
不在正中竖直时需要：按 [02 零点校准工具](./02-zero-tool) 定零并把打印值固化回
`config.h`，重新烧录。

## 6.4 跌倒门验证

把机器人分别摆成四种躺姿（见 [03 调试页 3.4](./03-debug-and-checks)），松手静止，
确认 0.5 秒内串口出现 `getup start pose=<对应姿态>` 并开始扶正。

## 6.5 完成标准

- [ ] `c` 打印 `accel bias ... (saved)`；
- [ ] `t` 两关节方向正确；
- [ ] `k` 中位与固化值一致（或已按 02 页重新定零并固化）；
- [ ] 四个躺姿都能触发 `getup start`。
