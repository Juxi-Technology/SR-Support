# 06 调试与标定

> **成品用户可跳过本页**：出厂已逐台完成标定与验证。仅在更换舵机/IMU、重新装盘、换齿，
> 或升级固件后怀疑标定漂移时，按本页顺序重新做一遍。

本页是装配、烧录、定零之后的**整机功能检查与标定**，按顺序做完即可投入使用。

## 6.1 遥测格式

串口每 250 ms 输出一行遥测，监控工具每 5 秒汇总一条：

```text
up -0.01 +0.02 +1.00 | w  0.0  0.0  0.0 | q +0.00 +0.00 | qd  0.0  0.0 | run
```

| 字段 | 含义 |
|---|---|
| `up` | 世界 up 向量在机体坐标下的分量（x 前、y 左、z 上） |
| `w` | 三轴角速度（rad/s） |
| `q` | 当前关节指令角（肩、肘，rad） |
| `qd` | 关节指令角速度 |
| 末尾 | `run` / `hold` / `manual` / `auto` |

快速硬件自检（在 `SR-Support` 目录、已激活 `.venv` 的终端里）：
`python tools/hw_check.py --port COM27` 会读取 0.6 秒遥测；加 `--tilt 8` 后用手倾斜机器人，
会打印 up/角速度范围与倾角变化，用来确认 IMU 不是卡死或方向接反。

## 6.2 IMU 检查与标定

1. 先按 [04 页 4.5](./04-assembly) 做机械方向自检（肩输出轴朝 IMU −Y、肘输出轴朝 IMU +X），
   然后让机器人静止直立，确认 `up≈(0, 0, 1)`，`w≈0`；
2. 机器人**站立在水平桌面**上保持静止，发送 `c` 同时标定陀螺与加速度计零点
   （提示 `calibrating gyro+accel...`；加速度零点写入 NVS，打印 `accel bias ... (saved)`
   才算成功；若提示 `rejected` 说明没放平或还在动，重新放稳再来）。
   **出厂时已标定并写入 NVS**，成品无需重做；仅在更换/重新安装 IMU 后发现躺姿倾角
   异常（第 5 步）时执行；
3. 缓慢左右、前后倾斜，确认 up 的 x/y 分量方向正确、无跳变；
4. 若 up 的 x 或 y 方向与预期相反，发送 `i` / `j` 翻转 IMU 轴符号后重新 `c`；
5. 躺姿检查：放倒静置 2 秒后 up 应稳定且与实际姿态一致（如侧躺的 −Y 姿态 up≈(0,−1,0)、
   底座面贴平）；若躺姿下 up 长期偏斜 5° 以上，往往就是加速度计零点未标定，重做第 2 步。

## 6.3 舵机检查与方向自检

| 检查 | 方法 | 预期 |
|---|---|---|
| 中位脉宽 | 发送 `k` | `centers: shoulder 1681 us, elbow 1456 us`（2026-11 视觉中位固化值；以 [05 页](./05-zero-tool) 重新标定为准） |
| 肩中位微调 | `o` / `p`（每次 ±10 µs） | 手臂竖直时 `q=0` |
| 方向 | `m 0.5 0` / `m 0 0.5` | 肩 + 使大臂向 −Y；肘 + 使小臂向 +X |
| 符号翻转 | `v`（肩）/ `b`（肘） | 方向反了才用 |
| 自检 | `t` | 两关节小幅动作后回中 |
| 回中 | `m 0 0` 或 `r` | 手臂竖直 |

关节限位（固件）：

- 肩：手动命令 `[-1.85, +1.82]` rad；肘：机械 `±1.55` rad（执行器内部可达）；
- `m` 手动命令的肘部限位为 `[-0.90, +0.70]` rad；
- PWM 输出范围 500–2500 µs，50 Hz。

发送 `t` 自检，确认：肩 `q>0` → 大臂向 **−Y**；肘 `q>0` → 小臂向 **+X**；
方向反了用 `v` / `b` 翻转，或重装舵盘。

## 6.4 中位核对

出厂已固化（肩 1681 µs / 肘 1456 µs），**成品可跳过**。DIY 流程中这一步应已在
[05 零点校准](./05-zero-tool) 完成并把脉宽固化回 `config.h`（改过就重烧）；这里用 `k`
核对中位与固化值一致即可。仅当换齿、拆装过手臂，或收臂后不在正中竖直时，才需要回
05 页重新定零并重烧。

## 6.5 四种躺姿与跌倒门

| 姿态 | 监视器 up | 物理含义 |
|---|---|---|
| `pitch_pos` | `(-1, 0, 0)` | 机体顶部指向 +X |
| `pitch_neg` | `(+1, 0, 0)` | 机体顶部指向 −X |
| `roll_pos` | `(0, +1, 0)` | 机体顶部指向 −Y |
| `roll_neg` | `(0, -1, 0)` | 机体顶部指向 +Y |

跌倒门条件（固件）：

```text
up_z < 0.30 且 |ω| < 0.9 rad/s，连续 25 拍（0.5 s）
```

满足后才会打印 `getup start pose=...` 并开始扶正。因此把机器人摆成躺姿后需要**松手并
保持静止约 0.5 秒**；放下后立即乱摆通常是手还在扶着或身体仍在滚动。

验证方法：分别把机器人摆成上表四种姿态，松手静止，观察串口是否在 0.5 秒内出现
`getup start pose=<对应姿态>`。

## 6.6 完成标准

- [ ] `c` 打印 `accel bias ... (saved)`；
- [ ] `t` 两关节方向正确；
- [ ] `k` 中位与固化值一致（或已按 05 页重新定零并固化）；
- [ ] 四个躺姿都能触发 `getup start`。
