# 01 基础知识

## 1.1 工作原理

SR-Support 是 2-DOF（肩 + 肘）主动自扶正装置：

- **机构**：一只两关节手臂安装在方形底座上，肩关节绕机体长轴摆动、肘关节折叠小臂；
- **感知**：6 轴 IMU 提供姿态四元数，固件用机体 up 向量把倒姿分为四类
  （`pitch_pos/neg`、`roll_pos/neg`，见 [05 调试页](./05-debug-and-checks) 5.4）；
- **执行**：参考序列执行器——每个倒姿对应一组路点（20 拍/路点、每拍限速 0.08 rad），
  手臂撑地/按压把身体撬回直立；`roll_neg` 另带肘部"楔形泵"与鞭甩下砸兜底；
- **兜底**：14 秒超时/姿态重规划/跌倒门自动重试；`roll_neg` 分阶段自适应保持，
  中途站起立即收臂；
- **验证**：四方向直接起身约 1–6 秒；同一模型可用于 MuJoCo 仿真与实机实时镜像
  （[09 页](./09-wifi-twin)）。

## 1.2 整机概览

| 项目 | 参数 |
|---|---|
| 底座 | 8.5 × 8.5 cm 方形；总高 4 cm（3.7 cm 灰色升高座 + 3 mm 红色底板） |
| 手臂 | 直立高度约 26 cm（上臂 + 前臂） |
| 整机质量 | 约 102 g（含两舵机与电控，待逐件称重校准） |
| 肩关节 | PTK7452MG；视觉零点坐标系下手动限位 `[-1.85, +1.82]` rad |
| 肘关节 | PTK7452MG，可用行程约 ±1.55 rad |
| 主控 | ESP32-S3-DevKitC-1（Arduino framework / PlatformIO） |
| 姿态 | Juxi ICM42670P 6 轴 IMU（I²C 地址 0x23，100 kHz） |
| 舵机驱动 | ESP32 LEDC，50 Hz，14 bit，脉宽 500–2500 µs |

## 1.4 工具

- 卡尺、万用表（通断/电压档）；
- 十字螺丝刀、内六角；
- 电脑：按 [02 环境准备](./02-environment) 安装 PlatformIO 与电脑端工具；

## 1.5 供电与安全

- 2× PTK7452MG 规格 **6 V / ≥5 A** 独立电源；7.4 V 可接近 4.5 kg·cm，但需实测发热/电流；
- **5 V 供电可用**（本项目实机即 5 V）：舵机堵转扭矩下降约 15%，`roll_neg` 方向更依赖
  楔形泵；若追求四方向更大余量，按规格用 6 V；
- 舵机电源端并联 1000–2200 µF 电解电容与 100 nF 陶瓷电容，串 5 A 保险丝，加电源开关；
- ESP32 用 USB-C 5 V 单独供电，与舵机电源**共地**；
- **不要把 6 V/7.4 V 接到 ESP32 的 5V/3V3**；不要用电脑 USB 口直接带两个舵机；
- 上电顺序：先接好共地与信号 → 舵机上电 → ESP32 上电；断电顺序相反。
