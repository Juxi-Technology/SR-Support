# 03 散件组装：打印、装配与接线

> **成品用户可跳过本页**：出厂已完成打印、装配、接线与走线检查（见
> [index 出厂状态](./index)）。仅在自组装或更换零件时按本页操作。

## 3.1 打印与检查

1. 打印 `footP`、`arm1P`、`arm2P`、`armhornP` ×2；
2. 用卡尺核对底座外形约 60 × 73 mm、升高座高 37 mm；底板厚 3 mm，总高 40 mm；
3. 检查舵机安装槽与 25T 舵盘配合，无干涉后再上螺丝；
4. 打印件逐件称重并记录（用于后续仿真模型质量校准）。

## 3.2 舵机准备（电气中位与舵盘齿位）

1. **电气中位（装配前）**：只接两路舵机信号（GPIO4/5）+ 舵机电源 + 共地，烧录找中辅助固件
   `firmware/releases/servo_center_ptk.bin`（烧到 `0x0`，方法见 [04 页 4.1](./04-build-flash)；
   该固件不依赖 IMU，仅用于装配找中）。从源码构建则用
   `pio run -d firmware/servo_center_ptk -t upload`。烧录后两只舵机输出 1520 µs 中位脉宽，
   先把舵盘朝上装好；
2. **肩舵机换齿**：把舵盘相对花键错开约 2 齿（≈29°），使固件中位脉宽（当前整机固化
   **1681 µs**，`SERVO_SHOULDER_CENTER_US`）对应手臂竖直的 `q=0`；肘舵机同理
   （**1456 µs**，`SERVO_CENTER_US`）；
3. 装舵盘、拧紧，手动检查行程无卡滞；
4. 方向约定（与仿真一致）：`shoulder +q` 使大臂向 **−Y**，`elbow +q` 使小臂向 **+X**；
   固件默认 `SERVO_SHOULDER_SIGN=-1`、`SERVO_ELBOW_SIGN=-1`。

> 齿位只是**粗对中**。精确零点必须在整机组装完成、主固件烧录（[04 页](./04-build-flash)）
> 之后，用 [06 零点校准](./06-zero-tool) 把目测竖直姿态定义为 q=0（`z` 不依赖 IMU，
> 任意姿态可用），再把打印脉宽写回 `config.h` 并重烧。即使装配时没有通电找中、直接装好，
> 也能这样定零；只有某侧行程不够（舵机被 500/2500 µs 限幅）时才需要拆盘重新错齿。
> 齿位决定两侧行程分配；固件手动限位（`Q_SHOULDER_MIN/MAX`）必须与实际行程一致，不要
> 随意放宽。定零后务必按 06 页把序列路点同步平移，否则扶正动作的物理姿态会漂移。

## 3.3 底座与手臂装配

1. 红色底板（3 mm）与灰色升高座（37 mm）用 M3 螺丝固定，组成 40 mm 高底座；
2. 肩舵机装入底座顶部舵机槽，舵盘朝上；
3. `arm1P`（上臂）安装在肩舵盘上，锁紧；
4. 肘舵机装入 `arm1P` 顶部，`armhornP` 连接 `arm2P`（前臂）；
5. 装配后手动把手臂摆到竖直（`q≈0`），确认与舵机中位一致。

## 3.4 接线

| 器件 | ESP32-S3 引脚 | 转接板 | 说明 |
|---|---|---|---|
| 肩舵机信号 | GPIO4 | CH1 | 50 Hz PWM |
| 肘舵机信号 | GPIO5 | CH2 | 50 Hz PWM |
| IMU SDA | GPIO6 | CH3 信号脚 | I²C 0x23，100 kHz |
| IMU SCL | GPIO7 | CH4 信号脚 | I²C 0x23，100 kHz |
| IMU VCC | 3V3 | — | **禁止接舵机 V+（6 V）** |
| IMU GND | GND | CH3/CH4 GND | 共地 |
| LED（可选） | GPIO2 | — | 状态灯 |
| 舵机 V+ | — | V+/GND 端子 | 6 V / ≥5 A |
| 舵机 GND | — | V+/GND 端子 | 与 ESP32 共地 |

注意事项：

- 转接板为无源直连：确认每个级联口的 V+/GND/信号顺序一致，插反会烧舵机或板子；
- I²C 线尽量短，不要与舵机线长距离并行；模块上拉一般为 3.3 V；
- 第一次上电先不接舵机，用万用表确认 V+ 电压与极性；再接一个舵机测试，最后接两个；
- 上电顺序：共地与信号 → 舵机电源 → ESP32 USB；断电相反。

## 3.5 IMU 安装方向

IMU 相对机体绕竖轴旋转了 +90° 安装。固件在 `config.h` 中启用 `IMU_YAW90`，
把 IMU 坐标系下的 up 向量换算到机体坐标：

```c
up_body = (up_imu.y, -up_imu.x, up_imu.z)
```

安装后请按 [05 调试页](./05-debug-and-checks) 检查：直立时 `up≈(0, 0, 1)`；
四种躺姿的 up 向量见 5.4 节表格。
